# API Codes

A list of the different response codes when using the API features of the Evolution X CDN ([here](https://cdn.evolution-x.org))

| Response Code | Explanation                           |
|---------------|---------------------------------------|
| T-0001        | Database or other internal error      |
| T-0002        | Bad request or Invalid parameters     |
| T-0003        | Unauthorised or Authentication failed |
| T-0004        | Method not allowed                    |
| T-0005        | File or Path not found                |
| T-0006        | Internal Server Error                 |
| T-0007        | Accepted or Processing                |
| T-0008        | Duplicate push request                |
