# Bender

Bender is the Evolution X team's internal bot. It serve the following usecases:
- Request to maintain an additional device without going through the application process
- Submit build request to the internal dashboard
- List and Manage current applications for maintainership
- Check any bot abuse cases for a user
- Send direct messages to users
- Add/Clear notes
- Unblock any user/ip from the CDN rate limits

The name comes from Futurama's character of the same name.
