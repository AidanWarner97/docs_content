# Scruffy

Scruffy is the Evolution X team's public facing bot.  It serves the following usecases:
- Fetching device information
- Note storage and display
- Maintainer lookup
- Donation lookup
- Check for any blocks on the CDN
- Initiate application process to maintain a device officially

The name comes from Futurama's character of the same name.
